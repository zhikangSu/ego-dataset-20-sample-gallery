# Record-level annotation excerpts

Bundled excerpts exist only where the displayed media can be tied to an official record/time base and redistribution is compatible with the company-sharing use case.

- `comind/21c13149_5_17.json` uses matching official healthcheck data (CC BY 4.0) and aligns device timestamps to the bundled clips.

No annotation from another record is presented as ground truth for a displayed sample. Open-AoE, SHOW3D and HumanEgo annotations are loaded directly from their official hosts in the browser instead of being copied here. Ropedia, Assembly101 and HD-EPIC remain source-only because their redistribution terms are not suitable or not explicit enough for this public company-facing gallery.
